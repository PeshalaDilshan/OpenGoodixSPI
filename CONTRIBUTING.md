# Contributing to OpenGoodixSPI

Thank you for your interest in contributing.

## Before You Start

1. Ensure you are running Linux kernel 6.x+
2. Be comfortable with kernel-space C
3. Understand SPI subsystem basics

## Development Rules

- Follow Linux kernel coding style
- No deprecated APIs
- Document assumptions clearly
- Keep commits small and focused
- Use descriptive commit messages

## Reporting Issues

Please include:

- Laptop model
- Kernel version
- Full dmesg logs
- SPI device info
- Reproduction steps

## Pull Requests

PRs must:
- Compile without warnings
- Include explanation of architectural changes
- Avoid breaking existing code

## Code Review Standard

This project aims for upstream-quality code.
Expect technical review and feedback.
